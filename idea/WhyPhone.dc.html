PhoneLab ／ 根拠

なぜ、スマホなのか

「みんな持っているから」だけでは理由にならない。実験が減っている原因が器具と準備にあり、その器具の代わりになるセンサーが手元にあり、精度が授業の判定に足りて、配布が URL 一つで済む。この四つが揃って初めて、スマホが実験器具になる。

1　実験が減る原因は器具と準備

12年連続

小中高の理科で「最も困っていること」は観察・実験機器の不足。平成25年度の調査から12年連続。

理科教員の66%が準備・片付けの時間不足。週1回以上実験する教員は55%、経験5年未満では49%。

日本理科教育振興協会 令和6年度充足調査（設備予算を求める同協会の要望書より）／ JST 中学校理科教育実態調査（独立した調査）

2　センサーは既に手元にある

97.1%

高校生のスマホ利用率で、うち自分専用が99.1%。中学生は84.8%（専用95.4%）。加速度、ジャイロ、マイク、カメラが一人一台ぶん、机の上にある。

高校の1人1台端末は設置者の41.6%が保護者負担（BYOD）。端末があることを前提にした学校が既に4割。

こども家庭庁 令和7年度速報 ／ 文科省 高等学校段階における学習者用端末の整備状況（令和6年度当初）

3　専用センサーは買うと高い

$99〜119

教育用の無線加速度センサー1台の価格。8班ぶんで約15万円、学年で揃えると数十万円。買っても校内で共有し、準備と片付けが要る。

国は理科設備の購入費を半分補助しているが、それでも「機器の不足」が最大の困りごとのまま。

Vernier Go Direct、PASCO Wireless の公表価格 ／ 文科省 理科教育設備整備費等補助金

4　精度は授業の判定に足りる

1〜3%

スマホの加速度センサーで重力加速度を測ったときの相対誤差。授業で決めたいのは「予想の差が許容誤差を超えるか」であって、小数第3位ではない。振り子の周期差 0.05 s、落下時間の差 0.09 s は、この精度で十分に見える。

phyphox を用いた測定研究、European Journal of Physics のスマホ実験室レビュー（2026）

5　配布は URL 一つ、審査員も自分の端末で

0インストール

ブラウザの DeviceMotion、getUserMedia、Web Audio で加速度・回転・音・映像が取れる。アプリストアも管理者配布もいらない。自分の端末で測ると、実験が自分の話になる。

MDN Web API 仕様 ／ 金沢工業大学 事例報告（携帯機器の加速度センサーを用いた運動の測定実験）

phyphox やストップウォッチと、何が違うのか

測定器としては phyphox が上

センサーの種類も実験集も PhoneLab は勝てないし、勝とうとしない。

足すのは反証実験の選択

生徒の予想を区別できる実験を、部品・許容誤差・安全条件から Agent が選ぶ。

足すのは保留と統制

二系統の検査で怪しいデータを止め、センサー許可を実験単位で管理し、記録に署名する。

手で測れない実験を優先

落下の 0.45 秒、音の高さ、うなりは、ストップウォッチでは測れない。振り子はその入口。

それでも足りない場面と、その逃げ道

校則でスマホを授業に持ち込めない

GIGA端末でカメラ・マイクの実験を行い、加速度の実験は家庭学習と自由研究へ回す。教師が学級ごとに切り替える。

GIGA端末の6割は ChromeOS で加速度がない

端末の能力を検出してカタログを絞る。自由落下、共鳴、うなり、音速はカメラとマイクだけで成立する。iPadOS の31%は加速度も使える。

機種でレートも軸も違う

だから Verifier が欠測・飽和・二系統不一致を検査し、揺れたら結論を保留する。機種差は隠さず、保留の理由として見せる。
