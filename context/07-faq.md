# 07. FAQ（公式全文の整理）

## エントリーについて

**Q: エントリーまでの流れを教えてください**
A: 本ページの「申し込む」ボタンから、Zennアカウントでログインの上エントリーしてください。エントリー後、ダッシュボードに表示される参加者情報フォーム（Googleフォーム）に氏名・所属などをご入力いただくと、参加登録完了となります。

**Q: チームで参加する場合、メンバー全員のエントリーが必要ですか？**
A: 必要です。代表者・メンバーともに参加登録をお願いいたします。

**Q: エントリー後は何をすればいいですか？**
A: ダッシュボードに表示される参加者情報フォーム（Googleフォーム）に氏名・所属などをご入力ください。入力が完了すると参加登録完了となり、プロジェクトを作成できるようになります。

**Q: チームで参加する場合、ダッシュボードでどのような操作を行えばいいですか？**
A: 代表者の方がダッシュボードからプロジェクトを作成し、エントリーしたメンバーをプロジェクトに招待する流れになります。

**Q: チームメンバーの追加・脱退はいつまでできますか？**
A: 提出締切（2026年10月15日（木）23:59）まで可能です。プロジェクトの提出後も、締切までは追加・脱退できます。締切後は変更できません。

**Q: エントリーの締切はいつですか？**
A: 2026年10月15日（木）23:59です。プロジェクトの提出締切も同日です。

**Q: 参加を取り消したくなった場合はどうすればいいですか？**
A: エントリーを取り消す操作はご用意していません。プロジェクトを提出しないまま締切を迎えていただいて問題ありません。ペナルティも特にありません。

## 参加資格について

**Q: 非常勤や兼業（フリーランス）でも「政府機関の職員」に該当しますか？**
A: 該当するためハッカソンにご参加頂けません。

**Q: 申し込みの後にチームを組成できますか？**
A: Discordに専用チャンネルを設けますのでそちらでメンバー募集しチームビルディングして頂けます。

**Q: ハッカソンのチームへの参加にはスキル面の条件がありますか？**
A: ありません。Discordにおいてご自身のスキルや関心について発信し、コミュニケーションを経てチームに参加頂けたら幸いです。

**Q: 同一メンバーによって複数のプロジェクトを投稿することは可能ですか？**
A: 可能です。ダッシュボード上でプロジェクトをそれぞれ作成し、個別にご提出ください。

**Q: 複数のプロジェクトに関わることで審査が不利になるなどの影響はありますか？**
A: ありません。プロジェクトそのものへの評価を行います。

**Q: ミニハッカソンだけの参加でも大丈夫ですか？**
A: はい。ミニハッカソンのみの参加が可能で、その成果をもって本戦へ進めます。

## 提出物について

**Q: WEBアプリかネイティブアプリかの指定はありますか？**
A: どちらでも構いません。ただし、開発プロジェクト条件（Google Cloud アプリケーション実行プロダクトの利用）は満たす必要があります。

**Q: ネイティブアプリ（スマートフォンアプリ）の場合、デプロイしたURLには何を記載すればいいですか？**
A: 可能な限りWeb版を公開し、そのURLをご記載ください。Webブラウザでの実現が難しい機能については、搭載されていなくても問題ありません。Web版の作成が難しい場合は、ネイティブアプリである旨と事情を説明したGitHub公開ページ（READMEなど）をご用意いただき、そのURLをご記載ください。審査時の申し送り事項として管理いたします。

**Q: ネイティブアプリの場合、審査はどのように行われますか？**
A: 審査員がリモートで審査を行う関係上、実機での動作確認が難しいため、デモ動画を中心に審査いたします。モバイルアプリならではの体験も可能な限り考慮して審査いたします。

**Q: ローカル環境で動けばそれでいいですか？クラウドへデプロイしておく必要がありますか？**
A: Google Cloud へのデプロイをお願いいたします。

**Q: Gemini API は AI Studio からの直接利用でも条件を満たしますか？**
A: はい、直接利用も可能です。ただし、開発プロジェクト条件のとおり、Google Cloud アプリケーション実行プロダクトの利用は別途必須です。

**Q: Cloud Functions for Firebase を利用することで、Google Cloud アプリケーション実行プロダクトの条件を満たしますか？**
A: 条件を満たします。

**Q: Firebase の App Hosting を利用することで、Google Cloud アプリケーション実行プロダクトの条件を満たしますか？**
A: 条件を満たします。

**Q: Firebase 経由で Gemini API を利用することで、Google Cloud AI 技術の条件を満たしますか？**
A: 条件を満たします。

**Q: Firebase Extension を利用することで、Google Cloud アプリケーション実行プロダクトの条件を満たしますか？**
A: Firebase Extension のみでは条件を満たしません。

**Q: プロジェクトコードは、どのレベルまで含めないといけないですか？**
A: 可能な範囲で問題ございません。ただし、今回どの部分を開発したのか、パッケージ化している部分はどこかなどの構成の説明は必ず加えてください。主要機能がモックではなく実際に実装されていることが分かる程度に公開した上で、ご提出いただければ幸いです。

**Q: Googleアカウントは企業のもの、個人のものどちらがいいですか？**
A: セキュリティポリシーによりGeminiなどに接続できない場合があるため、個人のアカウントでのエントリーをおすすめしております。

**Q: プロジェクトのコードリポジトリのURLは何に使いますか？**
A: 動作確認ならびに審査に用います。

**Q: 動いている環境がdev環境でも良いでしょうか？**
A: 問題ございません。動いているところの確認さえできれば問題ないという考え方になります。

**Q: ハッカソン後も開発を進めていきたいと考えているのですが、こちらは自由に実施しても良いでしょうか。**
A: 審査のため提出締切から12月1日（最終審査）までの間は、提出されたリポジトリには修正を加えないようよろしくお願いいたします。この期間も開発継続されたい場合はタグかブランチを切って頂く形でお願いいたします。

**Q: 提出後に記事やリポジトリ、動画の修正を加えてもいいですか？**
A: 提出時点の成果物を評価するため、提出後の各コンテンツの修正をご遠慮ください。

**Q: ハッカソン登録以前より個人/チームで開発を進めていたプロジェクトについて、ハッカソン期間中に改良・機能追加などの開発をして、成果物として提出してもいいですか？**
A: ハッカソンはあくまで競技ですので、本イベントの開始時点で一定進捗していたプロジェクトの提出は、公平性の観点からお控えください。

## クーポン利用・費用について

**Q: クーポン利用の際、クレジットカード情報の入力は必須ですか？**
A: 必須です。

**Q: クーポンを利用期限までにアクティベートしそびれてしまいました。再発行をお願いできますか？**
A: 再発行にはご対応しておりません。

**Q: 本ハッカソンで使用するGoogle Cloudの費用は自己負担ですか？**
A: 自己負担になります。

**Q: 学生向けの開発費用の補助はありますか？**
A: 参加者ごとに300ドル分のクーポンをメールで配布しています。数に限りがあります。

## スケジュールについて

**Q: 参加登録・提出の締切期限は当日の23:59まで という解釈でよろしいでしょうか？**
A: ご認識の通りです。

**Q: 審査に通過しなかった場合連絡はありますか？**
A: はい。審査の都合上、ご提出いただいたすべてのプロジェクトについて、1次審査後・2次審査後にそれぞれ通過・落選のご連絡を差し上げます。落選のご連絡を省略することはできませんので、あらかじめご了承ください。
