PhoneLab スマホが実験器具。AI は答えを言わない。— 2026-09-17 時点で動いている範囲だけを描いた図

生徒が予想を書く → ラボ先生（Gemini）が予想を壊せる実験をカタログから選ぶ → 端末のセンサーで測る → 機械が検査して怪しければ保留 → 先生は学級を一目で見て、必要なら全端末を止める

生徒の端末（PWA、学校の iPad ／ 家のスマホ）

予想ゲート

「こうなると思う」を書くまで、実験もヒントもセンサーも出ない。理由が無ければラボ先生が 1 回だけ問い返す

端末内の測定と検査（生データは端末の外に出ない）

DeviceMotion（加速度・ジャイロ）／ Web Audio（マイク）を、承認した実験の秒数だけ読む

  • 二本の時計: ジャイロ ω×L と 加速度 √((|a|−g)L)、基本周波数と倍音
  • 検査: 欠測・飽和・雑音・二系統不一致 → 保留（結論を出さない）
  • 3, 2, 1 の合図、測り直し（3 回まで）、3 回の平均
加速度ジャイロマイク位置情報は永久に不要

記録（localStorage）と、先生に送る要約

予想・計画・許可・測定の特徴量・検査・判定・次の予測・ラボ先生との会話を一本に。先生へは 要約だけ（波形・音声は送らない）

教員画面（PC、学級コード＋教師 PIN）

予想の向きの分布 → いま見に行く子（保留・却下） → 全員の表（番号だけ） → 許可・家でやる実験の有効化 → 全端末停止（5 秒ごとに更新）

POST /api/plan（予想・候補の id・学級コード）
POST /api/chat（考えを書いてから）
POST /api/records（要約）
GET /api/class（2 秒ごと、halted）
POST /api/class/…/halt・policy（PIN）

Cloud Run（asia-northeast1）— FastAPI ＋ Google ADK 2.8

決定論の Policy（LLM は読まない）

禁止動作（落とす・高所・水・交通）／メモ内の指示（「検査を飛ばして」）／答えの要求 → モデルを呼ばずに却下・問い返し。却下は理由 3 つ＋代替実験

ラボ先生 = 2 つの LlmAgent（Gemini 3.5 Flash-Lite、thinking low）

  • Planner: 予想を読み、そのテーマの候補だけから 1 つ選ぶ。構造化出力 PlanOutput（変数・向き・実験 id・理由・問い返し）。答え（answers.py）は渡さない
  • Tutor: 測定のあとのふり返り。説明は生徒が自分の考えを書き、判定が出ているときだけプロンプトに入れる。10 往復まで

統制層 PolicyPlugin（ADK BasePlugin、Runner に一度登録）

before_run

先生が学級を止めていれば、エージェントを走らせない

before_model

回数上限（5 回 / 実験、10 往復 / 記録）ならモデルを呼ばない。温度・出力長・思考量を強制

after_model

候補外の実験 id は差し替え。理由に混じった結果の言葉、説明の漏えい語句（保留中は結果の言い回しも）は問い返しに差し替え
