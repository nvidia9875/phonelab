# 教科書の実験をどこまで扱えるか（学習指導要領との照合）

> 2026-09-15 調査。**中学を先に作り、高校は後から足す**方針（`flow.md` §7）。
> 対象: 『中学校学習指導要領（平成29年告示）解説 理科編』と教科書の観察・実験、『高等学校学習指導要領（平成30年告示）解説 理科編』と教科書の実験、学校の端末事情。
> 「未確認」は一次資料で確かめきれていないもの。

## 0. 結論

1. **中学の教科書の観察・実験 82 件（東京書籍 令和 7 年度版）のうち、端末で扱えるのは 13 件。カバー率 18%、測定器になるのは 5 件**。化学（試薬・加熱）、電気、顕微鏡の実験が多く、ブラウザからは測れない。**物理のうち光・音・力・運動に絞ると 12 件中 7 件（58%）**
2. **扱える 13 件のうち 10 件はカメラとマイクだけ（T0）で成り立つ**。Chromebook（GIGA 端末の 6 割、加速度なしの機種がある）でも動く
3. **教科書に番号付きの実験が無いのに、指導要領が実験を求めている項目**を PhoneLab が埋められる: 音の伝わり方（中 1）、力学的エネルギーの保存（中 3）、南中高度の季節変化と月の継続観察（中 3）
4. 解説そのものが「各種のセンサを用いた計測を行い、通常では計測しにくい量や変化を数値化あるいは視覚化」「動画のコマ送り」「コンピュータで音を波形表示」を例に挙げている。**端末で測ることは指導要領の想定内**
5. 高校は物理基礎がカバー率 59%、基礎 4 科目全体で 39%。共通テストは実験題材が中心で、差がつくのはグラフの読み取り（4.4）
6. **振り子の「周期」は中学の単元ではない**（小 5「振り子の運動」と高校「物理」の単振動）。中学では中 3「力学的エネルギーの保存」の実験として問いを組み替える（6 章）

説明文で言えること: 「教科書の実験を全部置き換えるのではない。**測る実験（光・音・力・運動）の半分以上と、指導要領が求めているのに教科書に実験が無い項目**を、学校にある端末だけで埋める」。

## 1. 判定の決め方

| 判定 | 意味 |
|---|---|
| ◎ 測定器になる | 端末のセンサーで量を測り、その値で予想を確かめられる |
| ○ 補助になる | 時間・角度・色や明るさの相対値・方位など、結果を決める値の一部を端末が出す。器具は別に要る |
| × 代われない | 試薬の反応、顕微鏡、電流・温度・質量・力など、ブラウザから測れない量が主役。目で見れば済む観察（端末の出番が無い）もここに入れる |
| — 測定なし | 資料を読む、討論、モデルづくり |

- **カバー率** = (◎ + ○) ÷ (◎ + ○ + ×)。**測定器率** = ◎ ÷ (◎ + ○ + ×)。「—」は分母に入れない
- 写真をノート代わりに撮るだけのものは ○ に数えない
- 最低ティア: その実験が成り立つ一番低い端末の段階（2 章）

## 2. 端末の現実

### 2.1 授業で使える端末

| | 中学校 | 高校 |
|---|---|---|
| 授業の端末 | **GIGA 端末**（学校配備） | **BYOD の PC かタブレット**が主流 |
| 私物スマホ | 2020 年の文科省通知で **原則持込み禁止**（4 条件で容認）。理科の授業で使うのは原則として想定外 | 「1 人 1 台端末としては不可」の県が多い（群馬県、奈良県立宇陀高校）。神奈川県は 2020 年に県立 144 校で私物スマホを授業に使える環境を整えた前例がある（現行方針は未確認） |
| スマホでネット利用 | 84.8% | 97.1%（こども家庭庁 R7 速報） |
| OS | GIGA 第 2 期: ChromeOS 60% / iPadOS 31% / Windows 10%（MM総研 2025、小中合算。中学だけの内訳は未確認） | 私物スマホは 15〜19 歳で iPhone 約 6 割（モバイル社会研究所 2026） |

GIGA 第 2 期の最低スペック基準（文科省 2024/4/17）は **前後カメラ・タッチ・ペン・キーボード・マイク端子を必須**にしている。**加速度・ジャイロの要件は無い**。

### 2.2 ブラウザから取れるもの・取れないもの

- 取れる: 背面カメラ（約 30fps）、マイク（エコー除去を切れる）、音の出力、タッチの時刻、加速度・ジャイロ（センサーがある端末だけ。iOS はタップ起点で許可が要る）、方位の角度（iPhone / iPad / Android）
- **取れない**: 気圧、照度の値、磁束密度の値（Magnetometer はフラグの裏）、温度、120/240fps のスロー撮影。iPhone / iPad は Web Bluetooth も不可

### 2.3 ティア

| ティア | 使える機能 | 該当する端末 |
|---|---|---|
| **T0** | カメラ（前後）、マイク、スピーカー、タッチ | **すべての GIGA 端末**、私物スマホ全機種、高校 BYOD の PC・タブレット |
| **T1** | T0 ＋ 加速度（多くはジャイロも） | iPad、iPhone、Android、コンバーチブル Chromebook の多く（機種差あり）、センサー付き Windows 2-in-1 |
| **T2** | T1 ＋ 方位の角度 | iPhone、iPad、Android |
| **T3** | Chromium の拡張（Web Bluetooth の外付けセンサー、振動、ライト） | Android。Chromebook と Windows は Bluetooth のみ。iPad / iPhone は不可 |

**中学のテーマは、T0 だけで成り立つ版を必ず用意する**（Chromebook の学校で詰まないため）。

実装への影響: 現在の `app/web/src/store/status.ts` は `"DeviceMotionEvent" in window` しか見ていない。Chromebook や Windows では型があっても値が届かないことがあるので、**許可のあと数秒イベントが届くかで T1 を判定**する。

### 2.4 五感との対応

| 感覚 | 端末で使うもの | 中学での例 |
|---|---|---|
| 見る | カメラ（コマ送り、角度、色、明るさ） | 台車の運動、光の反射と屈折、雲量 |
| 聴く | マイク（振動数、振幅、反響） | 弦やボトルの音の高さ、音の速さ |
| 体で感じる | 加速度・ジャイロ | 振り子の速さ、ゆれ |
| 反応する | タッチの時刻 | 刺激に対する反応時間 |
| 向きを知る | 方位・傾き | 地層の向き、太陽や月の高さ |
| におい・味 | 使わない | 安全のため候補にしない（D7） |

### 3.4 教科書に番号付きの実験が無い項目（PhoneLab が埋められる隙間）

指導要領の本文は実験を求めているが、東京書籍の一覧に番号付きの活動が無い（教科書本文の小実験や図で扱っている可能性はあり、未確認）。

### 4.4 共通テストとのつながり（高校の入口の根拠）

- 問題作成方針（令和 9 年度）は基礎 4 科目で「観察，実験」「得られたデータを整理する過程などにおいて数学的な手法等を用いる問題」を明記
- 物理基礎は令和 7・8 年度とも大問 3 つのうち 2 つが実験題材。作問側は「実験の問題の正答率が高く実験自体の理解度は高いので，実験の意味などを問う問題が必要」と書いている
- **差がつくのはグラフの読み取り**: 令和 7 年度 物理基礎 第 2 問 問 5（グラフから g を求める）の正答率は約 2 割
- 化学基礎は令和 8 年度、50 点中「表やグラフを活用する問題 3 問、実験に関わる問題 4 問」
- 令和 8 年度 物理基礎 第 2 問は **スマートフォンのアプリで磁場を測る**台車の実験。ただし磁束密度の値はブラウザから取れないので、PhoneLab ではこの実験そのものは再現できない
- **振り子の周期**は高校「物理」の単振動（啓林館「物理」探究「単振り子の周期」、共通テスト 令和 7 年度 物理 第 2 問）。物理基礎ではなく、2〜3 年の発展科目
- 履修: 普通科では化学基礎 93%・生物基礎 94% がほぼ全員、3 科目目が物理基礎 66% か地学基礎 35%（平成 25 年度入学者。新課程の履修率は未確認）。**物理基礎を取らない生徒が 3 分の 1 いる**

→ 高校の入口は「自分で測ったグラフから傾きや値を読む」練習として見せると、点数を上げたい動機につながる。

## 5. 中学と高校で入口を分ける

| | 中学（先に作る） | 高校（後から） |
|---|---|---|
| 動機 | 興味を持つ、「なんで？」を自分で確かめて理解する | テストの点を上げる（共通テストの実験・グラフ問題） |
| 入口での選び方 | 「ふしぎ」から選ぶ（例: 「音の高さは何で決まる？」）。学年と単元は小さく添える | 科目と単元から選ぶ。共通テストで出た題材の印を付ける |
| 言葉 | 問いかけ中心（「どっちだと思う？」）。用語は後から添える | 教科書の用語と単位（加速度 m/s²、v-t グラフ、傾き） |
| イラスト | 実験の様子を描いた親しみやすい絵。手元の道具が分かる | 図解とグラフ。教科書の図に近い描き方 |
| ゲーム性 | 入れる（下の注意を守る）。反応時間チャレンジ、学級の予想の分布当て、「音のハンター」などの称号 | 控えめ。「測ったグラフから g を求める」小問、過去問の題材へのリンク |
| 参考リンク | 中学生向けの動画・読み物（リンク先は選定が要る） | 大学入試センターの問題と評価・分析報告書 |
| 端末の前提 | GIGA 端末（T0 必須、iPad なら T1〜T2）。私物スマホは家庭での実験に回す | BYOD の PC・タブレット（T0〜T1）。学校が認めれば私物スマホを補助のセンサーに |

**ゲーム性の注意**: 点数や称号は **予想が当たったかどうかには付けない**（D10「正解」「間違い」と言わない、AI は答えを言わない、と矛盾するため）。付けるのは「予想に理由を書いた」「二本目の時計が一致した」「保留から測り直した」「条件を 1 つだけ変えた」など、**科学の進め方**に対して。

実装への影響:
- カタログの各テーマに `school`（`jhs` / `hs`）、`grade`、`curriculum_ref`（例 `J3-11`、指導要領の項目）、`min_tier` を足す
- トップの入口で中学 / 高校を選ばせ、学級コードに学校種を持たせる（先生が決める。生徒は選び直さない）
- Planner に渡す候補リストは学校種とティアで絞る（`docs/experiments.md` §6 の端末能力の絞り込みを置き換える）

## 6. 中学を先にするときの MVP

いまのカタログと学年の対応:

提案:
1. **振り子は残し、問いを中 3「力学的エネルギーの保存」に組み替える**: 「高いところから放すほど、いちばん下では速い？」。6 画面と実測はそのまま使え、ジャイロの角速度の最大値を足すだけ。周期の 3 実験は高校（物理）に回す

   - B **音の高さ**（中 1 J1-16）: マイクだけ。`bottle_water` の設計が既にある
   - C **台車の動画**（中 3 J3-11, J3-12）: 記録タイマーの代わり。解説の例示どおりだが、動画解析の実装が一番重い
