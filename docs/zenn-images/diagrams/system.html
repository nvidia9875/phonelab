システム構成
端末で測り、Cloud Run の 1 つのサービスでエージェントを動かす
音声や加速度の生データは端末から出ない。サーバに届くのは、文と、検査を通った数値の要約だけ。
教室
Google Cloud ― Cloud Run（asia-northeast1）
Google Cloud のサービス
生徒の端末
学校の iPad・家のスマホ（Web アプリ）
  • 1予想と理由を書く。ラボ先生の提案を見て、センサーを使うのを自分で許可
  • 2許可した秒数だけ、センサー（加速度・ジャイロ・マイク）を読む
  • 3端末の中で計算と検査（二つの計算の一致・雑音・音割れ・途中の変化）。落ちたら保留
  • 42 条件を比べて判定。記録は端末（localStorage）に
  • 5測定中は 2 秒ごとに学級の停止を確認
送るのは数値の要約だけ（約 285 バイト）

  • ・許可の切り替え、全端末の測定を止める
  • ・先生の操作は監査記録に残る
