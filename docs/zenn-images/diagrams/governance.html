人が決めること
  • 生徒が、何を何秒読むかを見て承認してから測る
  • 先生が、使ってよいセンサー・家でやる実験を決める
  • 先生だけが、全端末の測定を止める・解除する
  • 見立ては提案だけ。設定を変えるのは先生のボタン
跡を残すこと
  • 何を読み、何を選び、統制が何を直したか＝判断の跡
  • 同じ段で、生徒の画面・教員画面・Cloud Trace に
  • トレースに生徒の文は入れない
  • 先生の操作は、追記だけの監査記録に
権限を絞ること
  • Cloud Run は専用のサービスアカウント、役割 4 つだけ
  • デモの PIN とセッションの署名鍵は Secret Manager
  • AI を呼べるのは学級の生徒だけ（番号と合言葉）
  • 音声や加速度の生データは端末から出さない
