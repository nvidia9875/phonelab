## 1. 撮る前に用意するもの

- [ ] 本番を最新にデプロイ（見本の記録 D-01〜D-06、Model Armor、次の一手、見立て が出ること）
- [ ] 実機の閾値（`docs/device-check.md` の結果）を反映済み
- [ ] 輪ゴム・ティッシュの空き箱、500 mL の細口ペットボトル、ひも 1 m・ジップ付きの袋・クッション、消しゴム
- [ ] iPad（ゆい役）、iPhone（家の振り子）、PC（教員画面）
- [ ] iPad と iPhone の通知を切る（おやすみモード）、画面の明るさを最大、文字サイズは標準
- [ ] 教員画面は学級 `DEMO-2026`、PIN は README。ブラウザの拡張・ブックマークバーを隠す
- [ ] 自己修正が出た Cloud Trace のトレース ID を 1 つ控える（教員画面の記録の「trace」リンクから開ける）

## 2. 撮影の順番（場所ごとにまとめる）

1. **机（明るい部屋）**: 0:00 の手元、0:35 のはじく手、1:05 の騒がしい隣の班（音楽を流して代用可）
2. **画面録画（iPad）**: 予想 → 計画 → 判断の跡 → 測定 → 結果 → 次の一手、保留、却下。テストモードは使わない（記録に「サンプル」と出るため）

## 3. 編集のメモ

- 字幕は上の表の文言をそのまま。1 枚 2 行まで、読める速さ（1 秒 6 文字）
