# デモ動画の絵コンテ（約 3 分、10/15 版）

> 流れ: **いまの理科の授業の課題 3 つ → メインタイトル → PhoneLab なら → 生徒の 1 回 → 保留・却下 → 先生の画面と停止 → 家でもやりたいとき → 家で → 仕組み → 数字 → 課題が解けた、で締める**。
