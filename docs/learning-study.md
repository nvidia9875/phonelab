# 学習効果を確かめる研究の設計（案、10/12）

> PhoneLab は「授業での学習効果は未検証」と書いている。このままでは「学びが深まる」とは言えない。
> ここでは、言えるようにするための最小の研究を設計する。根拠は 10/12 の教育研究の見直し（README の「学びの根拠」、`docs/zenn-article.md` 4 節）。

## 1. 何を確かめるか

**問い**: 中学 1 年「音の性質」で、PhoneLab を使うと、同じ材料・同じワークシートで AI なしに進めるより、音の大きさと高さを区別する理解が深まり、それが AI を外したあとも残るか。

- 比べる相手は「授業をしない」ではなく、**同じ予想→観察→説明（POE）のワークシートと同じ材料・同じ端末の測定で、AI（ラボ先生）だけが無い**授業。AI の効果だけを分けるため（センサーそのものは学力差が出ないという研究がある: Hochberg ら 2018、Gasparini ら 2026）
- 測るのは、**AI を外した事後テストと遅延テスト**。AI ありの練習中の成績は、AI を外したときの力とは別物（Bastani ら, PNAS 2025: 答えを出す AI で練習した群は AI を外すと 17% 下がった）

## 2. 設計

| 項目 | 内容 |
|---|---|
| 対象 | 中学 1 年、2 校 × 4 学級程度（学級単位で割り付けるので、学級数を確保する） |
| 割り付け | 学級ごとに PhoneLab 群と対照群（AI なしの POE）。学校内で半々 |
| 単元 | 「音の性質」の 2 時間（強さ・長さ・張りを変えて、大きさと高さを調べる） |
| 共通にするもの | 教師、時間、材料（輪ゴム・箱）、端末と測定画面、ワークシートの問い |
| 違うもの | PhoneLab 群だけ、ラボ先生が実験を選び、保留のあとの測り直しと次の一手を提案し、考えを書いたあとに説明する |
| テスト | 事前（単元の前）・事後（直後）・遅延（3〜4 週後）。すべて AI なし、紙か端末で |
| 問題 | 音の大きさと高さの区別、振動数と振幅、条件をそろえる考え方（変数制御）の概念問題 10〜15 問。既存の概念調査の項目を借りる（借りられるものを先に探す） |
| 実施の忠実度 | アプリの記録（予想を書いたか、理由の長さ、主張・証拠・理由の記入、保留と測り直し、説明を開いたか）で、使われ方を数える |
| 主な分析 | 遅延テストの得点を、事前テストを共変量にし、学級を入れた多層モデルで比べる |
| 倫理 | 学校長・保護者の同意。名前を集めない（番号だけ）。予想の本文は研究に使う範囲を同意書に書く |

## 3. 前もって決めておくこと

- **主な結果は 1 つ**（遅延テストの「大きさと高さの区別」）に決め、事前に登録する。あとから良い指標を選ばない
- 「AI があると使われなくなる」こともある（Khanmigo の報道）。使われ方（記録）を必ず並べて報告する
- 効果が出なくても公開する

## 4. その前にできる小さな確認（12/1 まで）

- 先生 1〜2 人に授業で 1 時間使ってもらい、記録を見る（予想を書く・理由を書く・保留から立て直す、が起きているか）。効果ではなく「使えるか」の確認
- 生徒 5〜10 人に、使ったあとで「強くはじくと何が変わった？」を聞く（考えの言葉を集める）

## 5. 言わないこと（この研究が終わるまで）

- 「学習効果がある」「理解が深まる」「AI が思い込みを直す」
- 「スマホのセンサーで学びが深まる」
- 「ハーバードの研究のように 2 倍学べる」（対象も設計も違う）
